# Food Ordering & Menu Management System (Android & Node.js REST API)

A full-stack mobile system consisting of a native Android client application connected to a Node.js/Express backend, designed for restaurant menu browsing, food ordering, and item management.

---

## Key Features

- **User & Authentication:** User management handling client profile operations.
- **Menu & Dish Management:** 
  - Manage food categories and detailed dish profiles (name, price, description).
  - Media file handling: Upload and serve dish images via Multer middleware.
- **RESTful API Integration:** Asynchronous data synchronization between Android client and Node.js server.

---

## Tech Stack & Architecture

- **Mobile Client:** Android Native (Java), Retrofit / HTTP Client, Material Design Components.
- **Backend Service:** Node.js, Express.js.
- **Database:** MongoDB (via Mongoose ODM).
- **File Upload:** Multer middleware.
- **Architecture:** Client - Server Architecture, RESTful API design.
